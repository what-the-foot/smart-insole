# 00. 프로젝트 개요

## 1. 한 줄 설명

스마트 인솔에서 수집한 양발 족압 데이터를 실시간으로 보여주고, 보행 중 나타나는 압력 분포와 좌우 차이를 분석하여 이해하기 쉬운 패턴 설명과 운동 가이드를 제공하는 서비스입니다.

## 2. 사용자 흐름

```text
로그인
→ 왼발·오른발 인솔 선택
→ 측정 시작
→ 양발 족압 히트맵과 연결 상태 확인
→ 측정 종료
→ 백엔드 분석
→ 좌우 차이·접촉 시간·압력 편중 결과 확인
→ 운동 가이드 확인
→ 과거 기록 비교
```

## 3. 구성 요소

| 구성 요소 | 책임 |
|---|---|
| 펌웨어 | FSR 센서를 읽고 BLE 패킷 전송 |
| Python BLE Receiver | BLE 파싱, 여러 샘플 배치, 백엔드 업로드 |
| Spring Boot | 검증, 저장, 분석, 인증, 실시간 메시지, 결과 API |
| React | 측정 제어, 양발 히트맵, 결과·운동·기록 UI |
| MySQL | 사용자, 기기, 원본, 품질, 분석 결과 저장 |

이 키트는 백엔드와 프론트엔드 구현에 집중합니다. 하드웨어가 없어도 fixture와 Mock Receiver로 개발할 수 있어야 합니다.

## 4. MVP 필수 기능

### 사용자·기기
- 회원가입, 로그인
- 내 기기 목록과 등록
- LEFT/RIGHT, 센서 수, 배치 버전 확인

### 측정
- 세션 생성·시작·종료·취소
- Receiver 원본 프레임 배치 업로드
- 중복 방지
- 누락·연결 상태·품질 기록

### 실시간
- 양발 히트맵
- 총압력, 접촉 상태, CoP
- 연결 상태, 품질, 경과 시간
- 한쪽 발이 끊겨도 다른 발 유지

### 분석
- 품질 검사
- 보정과 단순 필터
- 접촉 구간 검출
- 좌우 접촉 시간 차이
- 부위별 압력 비율
- 내측·외측 편중 경향
- 중립 패턴 코드

### 결과·기록
- 처리 중 상태
- 결과 조회
- 운동 추천
- 기록 목록과 상세

## 6. 핵심 데이터

### Pressure Frame

한쪽 발의 한 시점 센서 묶음입니다.

```json
{
  "deviceId": "b4b96290-ad73-42d9-ae21-1446f1258861",
  "footSide": "LEFT",
  "sequence": 10241,
  "deviceTimeMs": 102410,
  "sensorValues": [120, 245, 511, 803, 612, 301, 120, 80]
}
```

### Frame Batch

Receiver가 여러 프레임을 한 HTTP 요청으로 묶은 것입니다.

### Measurement Session

측정 시작부터 종료까지의 한 번의 측정 단위입니다.

### Calibration Profile

센서별 무부하 기준값과 크기 보정값입니다.

### Analysis Result

품질, 특징값, 패턴, 근거, 운동 추천을 포함한 결과입니다.

## 7. 표현 원칙

가능:

- 왼발과 오른발의 접촉 시간 차이가 관찰되었습니다.
- 중족부 압력이 상대적으로 높게 나타났습니다.
- 내측 압력이 상대적으로 집중되는 경향이 있습니다.
- 데이터 품질이 낮아 재측정을 권장합니다.

금지:

- 평발입니다.
- 족저근막염입니다.
- 치료됩니다.
- 교정이 보장됩니다.

## 8. 성공 기준

1. fixture로 양발 데이터를 전송할 수 있습니다.
2. 100Hz 원본이 중복 없이 저장됩니다.
3. 양발 실시간 히트맵이 표시됩니다.
4. 한쪽 발 끊김이 올바르게 표시됩니다.
5. 종료 후 분석이 실행됩니다.
6. 결과에 좌우 차이·압력 편중·품질이 나옵니다.
7. 다른 사용자의 REST·WebSocket 접근이 차단됩니다.
8. 핵심 흐름에 자동화 테스트가 있습니다.
9. 백엔드와 프론트가 같은 계약을 사용합니다.
